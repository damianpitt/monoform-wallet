# Naming decision: Monoform Wallet

The product name is **Monoform Wallet**, displayed simply as **Monoform** where context
is clear. The public repository is `damianpitt/monoform-wallet`.

## Meaning

“Monoform” expresses one deliberate form across three different monetary systems. The
name joins the single recovery root, consistent interface, monochrome visual language,
and narrow product scope.

Primary lines:

- Sovereign Money, One form, Three Chains
- Three chains. One form.
- A wallet you can read.
- Receive. Send. Verify.
- Few networks. Nothing hidden.

## The Monochrome Principle

“Monochrome” names the visual and engineering philosophy, not the product. The public
product does not use that name because established cryptocurrency businesses already
operate under it. Monoform uses a monochrome interface with at most one functional accent,
and applies the same restraint to code and dependencies.

The former “Sovereign Wallet” title was retired because an active open-source Bitcoin
wallet already uses it.
